## Left as they are, on purpose

- En dashes in number and date ranges ("1–30 hari", "1 Okt – 31 Okt"): correct
  range punctuation, not a clause connector. Some are also data keys.
- A lone "—" standing for an empty table cell.
- Dashes inside code comments.
- Lowercase "draft", "review", "driver" where they are API values, CSS
  variants or query keys, not text a person reads.
- Messages that come from the backend (for example a pull's review reason) are
  outside this console audit.
