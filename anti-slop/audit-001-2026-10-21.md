# antislop audit 001: Indonesian UI copy, whole console (2026-10-21)

Mode 2 (after). Nothing has been changed yet. Pick the numbers to fix; numbers
not mentioned are left alone.

**How this was done.** Every string literal and JSX text in `src/` (tests and
`src/components/ui/` excluded) was extracted with the TypeScript parser: 11,833
strings, of which 729 are sentence-length UI copy. All 729 were read. A spelling
check against the LibreOffice Indonesian and English dictionaries found no
misspellings, so this audit is about wording, not typos.

**Rules and priority.** Priority follows the antislop tier of the rule cited:
R-02 (Hard Gate: no em dash; text must feel natural and human) = HIGH, R-16
(Quality Lock: specific, plain language) = LOW.

**Left alone on purpose.** The client's own domain words stay: SA, Base,
Fakultatif, BAST, BA LO, LO, iVendor, SIM3LON, HPP, PPN, PKP, e-Faktur, Neraca,
jurnal, posting. A lone "—" standing in for an empty table cell is a
placeholder, not prose, and is not counted.

**Rewrites add no facts.** Each proposed text says only what the current text
or the code already says. Where the meaning needs the surrounding code to be
read first, the finding says "read context" and the final wording is settled
while fixing.

### 14. "Tenant" in user-facing text (48 sentences)
"Tenant" is a software word; operators say "perusahaan" (or "PT"). Proposed:
"perusahaan" in messages and descriptions, "sub-perusahaan" for sub-tenant,
keep "Tenant" only where admins manage the company structure. This is a
naming decision for you; findings 3, 7 and 10 assume "perusahaan".
